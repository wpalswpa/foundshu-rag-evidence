# 질문 이해와 담보 재정렬 모델 수립 계획

피넛의 공개판은 질문 하나에 모델을 한 번도 부르지 않는다. 사전과 낱말 규칙으로 질문을 읽고, 약관 색인에서 담보 후보를 고른다. 이 문서는 그중 두 단계(질문 읽기, 후보 고르기)에 모델을 들이는 계획이다. 지급 여부와 약관 문장은 지금처럼 원문 인용과 규칙이 맡고, 모델에게 맡기지 않는다.

현재 상태: 계획 단계다. 첫 단계(사람이 확정한 정답 세트)는 아직 시작하지 않았다.

## 규칙 방식이 막힌 곳

규칙으로 고친 만큼은 줄었다. 평가에 쓰지 않은 확인 질문 80개에서, 답의 담보 줄이 틀린 문항이 32개에서 1개로 줄었다(2026-11-12, 정답은 AI가 판정했고 사람이 확인하기 전이다). 하지만 고칠 때마다 같은 종류의 틀림이 다른 낱말로 다시 나왔다.

| 질문 | 잘못 읽은 낱말 | 결과 |
|---|---|---|
| 편도 떼어 냈어요 | 개념 이름 '편도 질환'의 '질환' | 뇌혈관·순환계 담보가 같이 나옴 |
| 크라운 | 개념 이름 '치과 치료'의 '치료' | 암 치료비가 같이 나옴 |
| 성대 결절로 수술했어요 | '궤양성대장염' 속의 '성대' | 대장 질환 담보를 거르지 못함 |
| 신장 이식 | '정신장애' 속의 '신장' | 정신장애 진단비가 첫 카드 |
| 다낭성 난소 증후군 | '증후군' | 다운증후군·VDT증후군 담보 |

사전에 없는 말도 못 읽는다. 담보를 못 찾은 질문에는 "온몸 사진 찍는 검사"(양전자단층촬영), "피를 못 만드는 병"(재생불량성빈혈)이 있다.

한편 약관에 문장이 없는 실무 지식은 모델로도 검색으로도 찾을 수 없다. 예를 들어 실손보험 표준화 전에 가입한 1세대 실손은 회사마다 약관이 달라, 다쳐서 받은 치과 치료나 정신과 질환의 보상 여부가 표준약관과 다르다. 이런 지식은 실무자가 확인한 문장을 출처와 함께 규칙 표에 넣는 길뿐이다.

## 이전 시도에서 배운 것

- **AI가 만든 정답으로 모델을 재면 부풀어 보인다.** 재정렬 모델(bge-reranker-v2-m3의 한국어 미세조정판, Apache-2.0)을 AI가 만든 질문과 표지 1,244개로 학습했다. 같은 출처의 시험 208문항에서는 상위 3 적중이 74.0%에서 97.1%로 올랐다. 하지만 사람이 고정한 검색 평가 20건에서는 18/20에서 17/20으로 오히려 줄어 채택하지 않았다.
- **차이가 흔들림보다 작으면 채택하지 않는다.** 약관을 칸으로 구조화한 층을 더한 비교는 실행마다 흔들리는 폭(±4~5점)보다 차이가 작아 넣지 않았다.
- **작은 생성 모델은 값을 지어낸다.** 같은 약관 원문을 로컬 4B 모델에 주면 원문에 없는 수술 종을 지어냈고, 14B 모델은 한 질문에 231초가 걸렸다.

## 순서와 통과 기준

앞 단계의 통과 기준을 넘어야 다음 단계로 간다.

| 단계 | 하는 일 | 통과 기준 |
|---|---|---|
| 1. 사람 정답 | 질문마다 '사건 → 질병·상해 → 확인할 보험금 분류 → 꼭 나와야 할 담보와 조항 → 나오면 안 되는 담보'를 실무자가 확정한다. 매주 20문항을 시스템이 답하고 실무자는 틀린 줄만 표시한다. 표시는 사례로 외우지 않고 규칙 표의 일반 규칙이나 출처가 붙은 문장으로 바꾼다 | 개발 세트 100문항 이상과, 손대지 않는 봉인 시험 세트 50문항 이상 |
| 2. 기준선 | 지금 규칙 방식을 1의 세트로 잰다 | 엉뚱한 대표 카드 수, 꼭 나와야 할 담보 찾음(상위 3), 분류 빠짐·엉뚱, 원인 틀림, 응답 시간이 한 명령으로 나온다 |
| 3. 재정렬 | 색인 검색이 고른 후보 40개를 뜻으로 다시 매긴다. 학습하지 않은 기본 모델과 이전 학습판을 비교하고, 다시 학습한다면 1의 사람 표지만 쓴다 | 봉인 시험에서 엉뚱한 대표 카드가 기준선보다 줄고, 담보 찾음과 분류가 나빠지지 않는다. 차이가 반복 실행의 흔들림보다 크다 |
| 4. 질문 읽기 | 질문을 정해진 칸(원인, 병·다친 곳, 부위, 행위, 병원 종류, 시점)으로 읽는다. 모델이 고르는 값은 질환 개념·질병분류 묶음처럼 정해진 목록 안에서만 받고, 목록 밖이면 지금 사전 방식으로 둔다 | 사전 밖 일상어에서 개념을 맞히는 비율이 오르고, 지어낸 값이 0이다. 노트북에서 질문당 1초 안팎 |
| 5. 서빙 | 3·4에서 채택한 것만 띄운다. 공개판 웹 컨테이너(메모리 1GiB)에는 싣지 않고 별도 서비스로 둔다 | 응답 시간 p95 2초 이하, 1천 질문당 비용 기록, 모델이 꺼져도 규칙 방식으로 답한다 |
| 6. 학습 고리 | 동의한 질문 기록 → 놓친 질문 검토 → 1의 판정 → 규칙 표 보강·재학습 → 봉인 시험 회귀 | 판마다 봉인 시험 숫자를 기록한다 |

## 하지 않는 것

- 서비스 경로에서 외부 AI를 부르거나 유료 호출을 하지 않는다.
- 모델이 지급 여부를 판단하지 않는다.
- AI가 만든 정답으로 채택을 정하지 않는다.
- 평가 결과에 맞춰 정답을 고치지 않는다.

## 왜 이 순서인가

모델을 먼저 고르면 무엇이 나아졌는지 잴 기준이 없다. 이전 재정렬 실험이 그랬다. AI가 만든 시험에서는 크게 나아 보였지만 사람 기준에서는 나아지지 않았다. 그래서 사람이 확정한 정답과 기준선을 먼저 만들고, 모델은 그 기준을 넘을 때만 들인다. 서빙 비용과 자리는 효과를 잰 뒤에 정한다.
