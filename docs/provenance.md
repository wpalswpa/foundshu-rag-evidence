# 구현의 출처와 공개 재현 범위

원본 찾았슈의 검색 규칙을 검토하기 쉽게 줄여 썼다. 서비스 소스 전체의 사본이나 원본 성능을 재현하는 패키지가 아니다.

| 공개 구현 | 원본 구성 | 가져온 것과 차이 |
|---|---|---|
| `bigrams`, `rank` | `app/knowledge.py`의 `bigrams`, `app/terms_evidence.py`의 `TermsIndex.search` | 글자 두 개와 제외 낱말, BM25 점수식을 가져왔다. 공개 예제에는 topic 필드·참조 카드가 없다 |
| `retrieve`의 범위 선택 | `policy_rag.retrieve` | 회사·상품·판본으로 한 문서 선택 후 특약 범위를 제한한다. 원본의 개념 사전과 사건 판정 규칙은 제외했다 |
| `valid_citation` | `app/terms_evidence.py`의 `TermsIndex.valid_citations` | 원문 위치·인용문·SHA-256 일치 조건을 작은 텍스트 자료에 적용했다. 원본 PDF 쪽 추출·문서 경로 검증은 포함하지 않는다 |
| `bundle` | `policy_rag.retrieve` | 같은 특약의 정의·제외·감액·기간·사건 조항을 함께 반환한다. 공개 예제에서는 질문에 일치하는 검색 결과가 없으면 보류한다 |

공개 말뭉치의 여섯 조각은 검색 차이를 드러내기 위해 새로 작성한 가상 문장이다. 실제 보험 약관과 지급 규칙이 아니다. 문서·특약 메타데이터는 신뢰하는 제작자가 부여한 것으로 가정한다. 공개 코드는 임의 업로드 자료의 신뢰성이나 잘못 붙인 메타데이터를 검증하지 않는다.

## 최신 제품 코드와의 경계

2026-10-12의 로컬 소스 파일을 읽어 위 대응을 확인했다. 약관·계약·진료 자료와 비밀값은 대조 입력으로 쓰지 않았다. 제품 코드 전체를 공개 저장소로 복사하지 않았다.

- `app/policy_rag.py`는 개념 확장, 부정·불확실성·타인 사건의 보류, 제한된 조건 검토를 포함한다. 이 공개 재현은 그 기능을 구현했다고 주장하지 않는다.
- `app/terms_evidence.py`는 PDF 파일 해시, 추출 쪽·위치, 공식 출처, 적용 시점과 계약 채택 여부를 다룬다. 공개 재현은 가상 텍스트의 해시·위치 일치만 확인한다. 같은 ID의 원문이 둘이면 출처를 임의로 고르지 않는다.
- `app/service/version_match.py`는 상품명·판본 표기와 특약 별칭을 대조하고, 불명확한 특약명을 보류한다. 공개 예제는 제작자가 정한 정확한 메타데이터를 받는다. 제품의 모든 이름 정규화·날짜·판본 판정을 이식한 것은 아니다.
- 원본 검색은 검증된 PDF 조각을 대상으로 한다. 공개 검색은 인용 검증을 통과한 가상 조각에서 순위를 계산한다. 문서 ID 중복, 인용 필드 누락, 원문 타입 오류, 계약 객체 누락은 회귀 검사로 확인한다. 임의 외부 말뭉치 전체의 스키마 검증기는 아니다.

대조한 로컬 소스의 SHA-256이다. 비공개 소스의 버전을 구분하며 공개 재현의 성능 증명으로 사용하지 않는다.

| 원본 코드 | SHA-256 |
|---|---|
| `app/knowledge.py` | `657be8e6c6c0b57add11395910558b382698af154a55e2463b6c17d6d805424b` |
| `app/terms_evidence.py` | `ba7b794b1cadda64890c11a8e92d48d128a0e6b42a9e309c25ed58853b383bf7` |
| `app/policy_rag.py` | `d0a424321b5203228ce44864deba511d90d139abe1b0221a24037b0e89239327` |
| `app/service/version_match.py` | `a692379064b89d515cd8623f933dcb85ab154fddadc23699a08fda85a4e4e487` |

원본 비교 실행에 사용한 구성요소와 평가 입력의 해시는 [원본 기록](../evidence/retrieval-record.json)에 있다. 이 해시는 출처를 구분하는 값이며, 비공개 원천을 가진 사람만 원본 파일과 대조할 수 있다. 공개 저장소의 검사는 기록의 산술 일치와 가상 예제의 행동을 확인한다.
