# 서비스 화면

공개 시연판과 같은 코드를 로컬에서 실행하고 예시 질문을 넣어 찍었다. 실제 고객 자료가 아니며, 이미지를 합성하거나 결과 문구를 바꾸지 않았다. 화면 아래의 입력 칸은 실제 화면처럼 답 위에 떠 있는 상태 그대로다. 화면별 SHA-256과 찍은 판은 [기록](../evidence/screenshots.json)에 있다.

| 화면 | 넣은 질문 | 보여 주는 것 | 범위 |
|---|---|---|---|
| [소개](images/intro.png) | 없음 | 첫 화면 제목, 흐르는 키워드 단추, 실제 답 화면 | 데스크톱 1440px |
| [화상 답](images/answer-burn.png) | 뜨거운 물에 데여서 화상을 입었어요 | 1번 화상진단비, 약관 정의를 옮긴 '기준' 줄, 지급 조항, 출처 쪽수 | 모바일 390px |
| [제외 대조](images/answer-exclusion.png) | 백내장 수술했어요 | 이름에 '백내장 제외'가 붙은 담보를 카드에서 빼고 안내 칸에 남김, 면책 문장에 걸린 담보는 뒤로 | 모바일 390px |
| [되묻기](images/clarify.png) | 보험금을 적게 받았어요 | 경위가 없어 대표 사유 네 가지를 선택지로 보임 | 모바일 390px |

화면 속 약관 문장은 보험사가 공시한 약관의 인용이다. 담보 카드는 질문한 사람의 계약이 아니라 색인된 다른 보험사 약관의 예시이고, 모든 카드가 '확인 필요'인 것은 검색만 방식이 지급 여부를 단정하지 않기 때문이다. 지급 확정 결과로 읽으면 안 된다.
