# 서비스 화면

공개 시연판(2026-11-12, 배포 판 00122)에 예시 질문을 넣어 실제 브라우저로 찍었다. 실제 고객 자료가 아니며, 이미지를 합성하거나 결과 문구를 바꾸지 않았다. 화면별 SHA-256과 찍은 판은 [기록](../evidence/screenshots.json)에 있다.

찍은 방법:
- 답 화면은 휴대폰 크기(390×844)로, 보여 줄 칸까지 스크롤한 뒤 화면 그대로 찍었다.
- 아래에 떠 있는 입력 칸과 '결과 보기' 단추는 실제 화면처럼 그대로 두었다.
- 질문 저장 동의 막대는 답을 가리지 않도록 '동의 안 함'을 눌러 닫았다.
- 소개 화면은 캐릭터가 움직이는 중간에 찍히지 않게 '움직임 줄이기'로 찍었다.

화면 속 약관 문장은 보험사가 공시한 약관의 인용이다. 담보는 질문한 사람의 계약이 아니라 색인된 다른 보험사 약관의 예시이고, 지급 여부를 판정한 결과가 아니다.
