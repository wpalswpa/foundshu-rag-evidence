# 서비스 화면

공개 시연판에 배포한 판(2026-11-12, 소개 화면은 foundshu-00050, 대화 화면은 foundshu-00047)과 같은 코드를 로컬에서 실행하고 예시 질문을 넣어 찍었다. 실제 고객 자료가 아니며, 이미지를 합성하거나 결과 문구를 바꾸지 않았다. 화면 아래의 입력 칸은 실제 화면처럼 답 위에 떠 있는 상태 그대로다. 질문 저장 동의 막대는 답을 가리지 않도록 '동의 안 함'을 눌러 닫은 뒤 찍었다. 화면별 SHA-256과 찍은 판은 [기록](../evidence/screenshots.json)에 있다.

화면 속 약관 문장은 보험사가 공시한 약관의 인용이다. 담보 카드는 질문한 사람의 계약이 아니라 색인된 다른 보험사 약관의 예시이고, 모든 카드가 '확인 필요'인 것은 검색만 방식이 지급 여부를 단정하지 않기 때문이다. 지급 확정 결과로 읽으면 안 된다.
